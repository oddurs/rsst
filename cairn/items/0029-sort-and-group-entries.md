## Problem

Entries are always newest-first within a single feed. There is no way to see everything across all feeds in date order.

## Proposal

A combined 'all feeds' view sorted by date, plus a sort toggle for oldest-first.

## Acceptance criteria

- [ ] An all-feeds view lists every entry in date order.
- [ ] Sort order toggles and is remembered.
- [ ] Undated entries sort last in both directions.
