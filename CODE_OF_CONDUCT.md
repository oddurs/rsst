# Code of conduct

## The short version

Be decent. Assume good faith. Criticise code, not people.

This is a small project; it does not need elaborate governance. It does need
everyone taking part to be someone others are willing to work with.

## What that means

Welcome: technical disagreement, strong opinions clearly argued, saying "I think
this is wrong and here is why", admitting you were wrong, asking questions that
seem obvious.

Not welcome: personal attacks, demeaning or discriminatory comments, harassment
of any kind, sustained disruption, publishing anyone's private information.

## Scope

This applies in issues, pull requests, commit messages and anywhere else the
project is being discussed.

## Reporting

If someone is behaving this way, report it privately to the maintainer through
[GitHub](https://github.com/oddurs) rather than in a public thread. Reports are
handled confidentially, and a report made in good faith will never count against
the person making it.

Responses are proportionate: usually a private word, sometimes an edited or
removed comment, and for anything sustained or severe, a block.

## Attribution

The spirit of this follows the [Contributor Covenant], trimmed to something a
project this size can actually honour.
